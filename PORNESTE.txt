Pontaj automat IBM
==================

Cel mai simplu: dublu-click pe Pontaj.command (Mac) sau Pontaj.bat
(Windows). Prima data instaleaza singur ce lipseste (Python, Playwright,
Google Chrome), apoi deschide interfata in browser.

Pe Mac, prima data, macOS spune '"Pontaj.command" Not Opened' - e
Gatekeeper, blocheaza orice script descarcat si nesemnat de Apple. Apasa
Done, apoi System Settings -> Privacy & Security -> jos de tot,
"Pontaj.command was blocked" -> Open Anyway, si dublu-click din nou.
(Sau click dreapta -> Open, pe macOS-urile mai vechi.) O singura data.

Pe Windows, la ecranul albastru SmartScreen: More info -> Run anyway.

Din terminal, acelasi lucru:

1. Instaleaza o singura data (in acest folder, din terminal / PowerShell):

       pip install playwright

2. Porneste interfata:

       python gui.py

   Se deschide singura in browser. La fiecare rulare se apasa Save
   (altfel orele nu raman), dar niciodata Submit - pe ala il apesi tu.
   Bifeaza "Doar verifica" daca vrei sa vezi ce ar face, fara sa salveze.

3. Cand apesi "Ponteaza", se deschide o fereastra Chromium. Daca IBM cere
   login, il faci tu acolo (w3id + parola sau passkey + 2FA) si scriptul
   continua singur. w3id tine sesiunea cateva ore, deci de obicei nu
   te intreaba de doua ori in aceeasi zi.

Fara interfata, direct din linia de comanda:

       python pontaj_ibm.py
       python pontaj_ibm.py --oncall "9-15" --overtime "16=3"
       python pontaj_ibm.py --vacation "14-16"
       python pontaj_ibm.py --holiday "15"
